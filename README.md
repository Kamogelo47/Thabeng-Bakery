## Project Overview

Thabeng Bakery is a small bakery website developed as part of the WEDE5020 Web Development module.

The website provides customers with information about the bakery, its products and services, and ways to make enquiries and contact the business.

The website was designed to provide a simple, visually appealing and user-friendly online presence for Thabeng Bakery.

The website consists of five main pages:

- Home
- About Us
- Products
- Enquiry
- Contact

---

## Website Goals and Objectives

The main goals of the Thabeng Bakery website are to:

- Establish a professional online presence for the bakery.
- Provide customers with information about the bakery.
- Showcase the bakery's products and baked goods.
- Allow customers to make product and custom cake enquiries.
- Provide customers with contact information and bakery locations.
- Create an easy-to-use navigation system.
- Provide a responsive website that can be viewed on different screen sizes.

---

## Key Features and Functionality

The website includes the following features:

- Responsive navigation menu.
- Homepage with bakery introduction and hero image.
- About Us page containing information about Thabeng Bakery.
- Products page displaying bakery products with images and descriptions.
- Enquiry page containing a customer enquiry form.
- Contact page containing business contact information and locations.
- Consistent visual design across the website.
- Responsive layout for desktop, tablet and mobile devices.
- HTML5 structure and CSS styling.
